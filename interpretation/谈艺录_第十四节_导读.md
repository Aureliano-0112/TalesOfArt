# 《谈艺录·第十四节》白话导读

> 李贺的"时间焦虑"——"天运"着眼，独与神仙作挽歌

---

## ★ 先记住一句话

**李贺除了"侘傺牢骚"之外，还有一个反复出现的主题：感于光阴之速、年命之短、世变无涯、人生有尽。别人吊古兴怀是为了及时行乐，李贺却"纯从天运着眼"——这是一种"出世法、远人情"。他不为朝代兴亡感伤，只为宇宙本身的无情而低徊。**

---

## 一、核心发现：一个"屡见不鲜"的作意

> **"细玩昌谷集，舍侘傺牢骚，时一抒泄而外，尚有一作意，屡见不鲜。其于光阴之速，年命之短，世变无涯，人生有尽，每感怆低徊，长言永叹。"**

（细读李贺集，除了失意的牢骚偶尔发泄之外，**还有一个反复出现的主题**：感叹光阴飞逝、寿命短促、世事变化无穷、人生有限，每每感伤低徊、长声叹息。）

## 二、关键区分：李贺"纯从天运着眼"

> **"他人或以吊古兴怀，遂尔及时行乐，长吉独纯从天运着眼，亦其出世法、远人情之一端也。"**

（别人或者凭吊古迹而抒发怀抱，于是**及时行乐**；李贺却**纯粹从"天运"（宇宙运行）着眼**——这也是他"出世法、远人情"的一个方面。）

> **这是一个很重要的辨析**：
> - 一般诗人的"时间感"往往落在**人事**上（朝代兴亡、功业难成），于是导向"及时行乐"。
> - 李贺的时间感是**宇宙性的、非人事的**——他看到的是"海变成陆、陆变成海"，是"劫灰飞尽古今平"，**与人的悲欢无关**。
> - 正因如此，他不去"及时行乐"，而是陷入一种更深的、近乎形而上的悲怆。

> **"所谓'世短意常多'，'人生无百岁，常怀千岁忧'者非耶。"**（这不就是古人说的"世短意常多""人生无百岁，常怀千岁忧"吗？）

## 三、【补订】几组精彩的例子

### 1. "斩龙足"——想射住太阳

- 《日出入行》想让后羿射日"使不得奔"。
- 《苦昼短》更发舒此意：**"吾将斩龙足，嚼龙肉，使之朝不得回，夜不得伏。自然老者不死，少者不哭。"**

（我要斩断烛龙的脚、嚼它的肉，让它早晨不能回去、夜晚不能潜伏——这样老者就不死、少者就不哭了。**这是以狂想对抗时间。**）

### 2. "海尘新生石山下" = "海沙变成石"

- 《天上谣》"海尘新生石山下"，即《古悠悠行》"**海沙变成石**"——**天上不多时，而人间已换世**。

### 3. 逢闰则一年稍迟

- 《相劝酒》"羲和骋六辔"，可参《十二月词·闰月》："**今岁何长来岁迟，王母移桃献天子，羲氏和氏迂龙辔。**"
- "**迂**"就是"缓"——逢闰年，一年过得稍慢，好像羲和稍稍缓了车速。
- 李商隐《河内诗》："**入门暗数一千春，愿去闰年留月小。**"——他**希望年岁过得更快**，就不愿羲和"迂辔"，反而盼他加鞭了。（**正反相对，极妙。**）

### 4. 仙寿虽长而有限

- 《浩歌》"王母桃花千遍红，彭祖、巫咸几回死"——**人寿纵长，比起神仙终究是夭**。
- 《官街鼓》"**几回天上葬神仙，漏声相将无断绝**"——**仙寿虽长也有尽，不如宇宙之无穷**。

> 袁中郎（袁宏道）《过黄粱祠》："**人间惟有李长吉，解与神仙作挽歌。**"（只有李贺，懂得替神仙写挽歌。）——"殆指此耶"。

## 四、与李白的对比

李白也有《日出入行》，大略说："人非元气，安得与之久徘徊……**吾将囊括大块，浩然与溟涬同科。**"

> **钱锺书的比较**：
> - 李白"**自天运立言，不及人事兴亡，与长吉差类**"（也是从天运着眼，不谈人事兴亡，和李贺相近）。
> - **但**李白"**乘化顺时**"（顺应自然变化），而李贺"**感流年而欲驻急景**"（感慨流年飞逝，想要留住急速消逝的时光）——**"背道以趣"**（方向完全相反）。

**一个是顺天安命，一个是逆天抗争。**

---

## 五、【附说】"寄语羲和快著鞭"

李商隐《夕阳楼》："**欲问孤鸿向何处，不知身世自悠悠**"——"尤堪为危涕坠心者矣"。

诗中用"羲和抶马"，以**黄仲则《绮怀》第十六首**结句为妙：

> "**茫茫来日愁如海，寄语羲和快著鞭。**"

（来日茫茫，愁如大海；我要告诉羲和——**快点赶车吧**。这是"厌生祈死"。）

**源头**：司空图《狂题》第十五首："**昨日流莺今日蝉，起来又是夕阳天。六龙飞辔长相窘，更忍乘危自著鞭。**"

> **黄仲则"特反用其语"**——司空图是劝人不要"自著鞭"（不要自寻死路），黄仲则反而"寄语羲和快著鞭"（请快点），"**厌生祈死，遂益令人惘惘不甘耳**"。

## 六、名词小词典

| 名词 | 说明 |
|---|---|
| 侘傺 | 失意、不得志 |
| 天运 | 宇宙自然的运行 |
| 羲和 | 神话中驾日车的神 |
| 烛龙 | 神话中衔烛照明的龙 |
| 劫灰 | 佛教语，劫火焚烧后的灰烬 |
| 三山下 | 指蓬莱等三神山，喻沧海桑田 |
| 迂辔 | 放缓车驾，喻时间走得慢 |
| 乘化顺时 | 顺应自然变化（李白） |
| 驻急景 | 留住飞逝的时光（李贺） |

## 七、金句摘录

1. **"其于光阴之速，年命之短，世变无涯，人生有尽，每感怆低徊，长言永叹。"**
2. **"皆深有感于日月逾迈，沧桑改换，而人事之代谢不与焉。"**
3. **"他人或以吊古兴怀，遂尔及时行乐，长吉独纯从天运着眼。"**
4. **"太白飘逸，此突兀也。"**
5. **"乘化顺时，视长吉之感流年而欲驻急景者，背道以趣。"**
6. **"人间惟有李长吉，解与神仙作挽歌。"**
