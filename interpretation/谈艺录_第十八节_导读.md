# 《谈艺录·第十八节》白话导读

> 王安石怎样学韩愈——以及"以文为诗"的极致与丑态：宋人爱用语助（虚字）入诗

---

## ★ 先记住一句话

**王安石的诗大量偷韩愈的"语""意""势"，尤其继承了他"善用语助（虚字）、以文为诗"的秘法。钱锺书由此梳理出一条从汉魏到唐宋的"虚字入诗"史，并给出一个精彩的定评：理学家用虚字，是"冗而腐"；竟陵派用虚字，是"险而酸"——而"兼酸与腐，极以文为诗之丑态者，为清高宗之六集"。**

本节篇幅极长，可以分**三段**读：荆公学韩、虚字入诗史、虚字对仗的流弊。

---

## 一、荆公学韩愈：偷语、偷意、偷势

### 起点：邵博的批评

邵氏《闻见后录》说：荆公既鄙夷韩愈"力去陈言"，**自己作《雪诗》又全袭韩愈语**。

> 钱锺书指出：荆公《读韩》"可怜无补费精神"，**本身就是韩愈《赠崔立之》的句子**（只把"益"字改成"补"字）。

### 荆公诗"自昌黎沾丐者，不知凡几"

| 荆公诗 | 出处（韩愈） |
|---|---|
| 《元丰行》"**田背坼如龟兆出**" | 韩愈《南山》"或如龟坼兆，或如卦分繇" |
| 《孔子》"圣人道大能亦博，学者所得皆秋毫" | 韩愈《送王秀才序》"孔子之道大而能博" |
| 《再用前韵寄蔡天启》"微言归易悟，捷若髭赴镊" | 韩愈《寄崔立之》"连年收科第，若摘颔底髭" |
| 《怀钟山》"何须更待黄粱熟，始觉人间是梦间" | 韩愈《遣兴》"须著人间比梦间" |

> **注意**："此皆不过**偷语偷意**，更有若皎然《诗式》所谓'**偷势**'者。"

**"偷势"的例子**：荆公《游土山示蔡天启》《用前韵赠叶致远》，"**全套昌黎《南山》诗'烂漫堆众皱'一段格调**"——偷的不是词句，而是**整体的气势与格调**。

## 二、核心：荆公善用"语助"，得昌黎之传

> **"荆公五七古善用语助，有以文为诗、浑灏古茂之致，此秘尤得昌黎之传。"**

（王安石的五七言古诗善用虚字，有"以文为诗"、浑厚古茂的风致——**这个秘诀尤其得自韩愈的传承**。）

### 溯源：虚字入诗的传统

钱锺书举出一条长长的源流：

- **周秦诗骚**、汉魏杂体歌行——杨恽《拊缶歌》、魏武帝乐府、蔡琰《悲愤诗》、《孔雀东南飞》、沈约《八景咏》，"**皆往往使语助以添迤逦之概**"。
- 极致在**陈子昂《幽州台歌》、李白《蜀道难》《战城南》**。
- **五言**中唐以前"斯体不多"。

> **关键区分**："然亦人不数篇，篇不数句，**多摇曳以添姿致，非顿勒以增气力**。"（大多只是摇曳生姿，不是用虚字来增加**气力**。）

### 陶渊明是转折点

> **"唐以前惟陶渊明通文于诗，稍引厥绪，朴茂流转，别开风格。"**

如"**结庐在人境，而无车马喧**""**孰是都不营，而以求其安**""**理也可奈何，且为陶一觞**""**馁也已矣夫，在昔余多师**"。

### 元结、韩愈推至极致

- 元结（次山）"参古文风格，语助无不可用，尤善使'焉'字、'而'字"。
- **韩愈则"荟萃诸家句法之长"**，元稹、白居易也能用虚字，但"**无昌黎之神通大力，充类至尽，穷态极妍**"。

> **韩愈的"而我"字**："昌黎亦善用'而'字，**尤善用'而我'字**，其秘盖发自刘绘"（刘绘《有所思》"别离安可再，而我更重之"）。
>
> 唐人中李白用得最多，如"**而我竟何为，寒苦坐相仍**"；韩愈"**而我于此时，恩光何由沾**"——"**胥有转巨石、挽狂澜之力**"。
>
> **荆公用"而我"字无不佳**，如"**而我方渺然，长波一归艇**""**岂鱼有此乐，而我与子无**"。

## 三、宋人"以虚字对仗出奇制胜"

近体诗里，用虚字作对仗，宋人"更以此出奇制胜"。钱锺书列了**一大批**：

| 作者 | 例句 |
|---|---|
| 王中父 | "命也岂终否，时乎不暂留" |
| 韩持国 | "用舍时焉耳，穷通命也欤" |
| 王安石 | "男儿独患无名尔，将相谁云有种哉" |
| 欧阳修 | "藏之十袭真无用，报以双金岂所宜" |
| 刘敞 | "贫且贱焉真耻也，壮之良者盍行乎" |
| 苏轼 | "君独未知其趣耳，臣今时复一中之" |
| 李师中 | "山如仁者静，风得圣之清" |
| 黄庭坚 | "夫然聊尔耳，得也自知之" |
| 陆游 | "谁其云者两黄鹄，何以报之双玉盘" |
| 方岳 | "翁之乐者山林也，客亦知夫水月乎" |

> **但钱锺书提醒**："**然窠臼易成，十数联以上，即相沿袭。**"（这种句式容易变成套路，十几联以上就开始互相沿袭了。）并举出大量"相犯""显袭""填匡格"的例子。

### 邵雍《击壤集》：自成路数

> **"宋人诗中有专用语助，自成路数，而当时无与于文流者，邵尧夫《击壤集》是也。"**

如"**无声无臭尽休也，不忮不求还得之**""**物皆有理我何者，天且不言人代之**"。

## 四、流弊：理学家、竟陵派的两种病

### 明代：陈白沙、庄定山

- 陈白沙"虚字对更少"，偶一为之"**生劲差似唐子西、韩子苍**"。
- 庄定山"虚字对较多"，如"**天乎贤孝真佳壻，诗也幽闲亦寿机**"——"**头巾气殊不可耐**"。

### 竟陵派：以语助为诗诀，成了笑柄

钟惺（伯敬）、谭元春（友夏）、蔡复一（敬夫）等人，把虚字用到了荒谬的地步：

- 钟惺："**何非寒其声**""**是为月之时**""**夫惟或隔之**"
- 谭元夏："**奇矣哉吾师**""**退言于水木**""**勤哉慎厥初**"
- 倪鸿宝："**及其老也戒，故诩舌之能**"

> **钱锺书的定评（本节最精警的一段）**：
>
> **"盖理学家用虚字，见其真率容易，故冗而腐；竟陵派用虚字，出于矫揉造作，故险而酸。一则文理通而不似诗，一则苦做诗而文理不通。"**
>
> （理学家用虚字，是图真率省事，所以**冗长而迂腐**；竟陵派用虚字，是矫揉造作，所以**险怪而酸涩**。一个文理通却不像诗，一个苦做诗却文理不通。）
>
> **"兼酸与腐，极以文为诗之丑态者，为清高宗之六集。"**
> （把"酸"和"腐"兼而有之、把"以文为诗"的丑态推到极致的，是**清高宗（乾隆）的六集**。）

> 宋太祖论"朱雀之门"所谓"**之乎者也，助得甚事**"——正是讥笑这种滥用虚字。

### 【补订】补充与调侃

- 陈士业《寒夜录》指出李端"好以语助入诗"，"顷钟谭多用此体"。
- 李元仲说钟谭甚避"庸腐"却"必至于庸腐"，因为"**专禁使事，全以语助点缀成文**"。
- 王渔洋（王士禛）讥竟陵派"多用焉、哉、乎、也等虚字成句，令人喷饭"——**但钱锺书指出：唐宋大家均有此体，明人为之者也不只竟陵一派**。

> **钱锺书对王渔洋的调侃**："王氏尝为班孟坚所谓'言语侍从之臣'，使其生当乾隆之世，或将**啮唇忍笑咽饭不敢喷而至于噎**欤？"（王士禛是"言语侍从之臣"，若生在乾隆朝，恐怕要咬着嘴唇忍住笑、连饭都不敢喷出来，直到噎住吧？）

## 五、名词小词典

| 名词 | 说明 |
|---|---|
| 偷语 / 偷意 / 偷势 | 皎然《诗式》分举的三种"偷"，"偷势"最高 |
| 语助 | 虚字，如之、乎、者、也、而、焉、哉 |
| 以文为诗 | 用散文句法、虚字写诗 |
| 而我 | 韩愈擅用、荆公擅用的虚字起句 |
| 击壤集 | 邵雍诗集，专以语助入诗自成路数 |
| 竟陵派 | 明代钟惺、谭元春一派，滥用虚字 |
| 之乎者也 | 宋太祖讥"朱雀之门"语 |
| 清高宗之六集 | 乾隆的诗集，钱锺书评为"以文为诗之丑态" |

## 七、给初学者的思考题

1. "偷语""偷意""偷势"有什么高下之分？为什么"偷势"最高？
2. 韩愈"善用语助"为什么被称为"以文为诗"的秘法？
3. "多摇曳以添姿致，非顿勒以增气力"——这两种用虚字的方式有什么不同？
4. 为什么说理学家用虚字是"冗而腐"、竟陵派是"险而酸"？
5. 钱锺书说乾隆的诗是"以文为诗之丑态"，这个评价是否太苛刻？"以文为诗"的边界在哪里？
