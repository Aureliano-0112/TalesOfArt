# 《谈艺录·第十二节》白话导读

> 李贺的"代词"——不肯直说物名的奇才，与"奇才而非大才"之评

---

## ★ 先记住一句话

**李贺写诗爱用"代词"，不肯直说物名：剑叫"玉龙"，酒叫"琥珀"，天叫"圆苍"，秋花叫"冷红"，春草叫"寒绿"。这是他"避熟求生"的苦心，但也带来一个致命的短处——"牛鬼蛇神，所以破常也；代词尖新，所以文浅也"。钱锺书的结论是：李贺是"奇才"，但不是"大才"。**

---

## 一、起点：李贺好用代词

> **"长吉又好用代词，不肯直说物名。如剑曰'玉龙'，酒曰'琥珀'，天曰'圆苍'，秋花曰'冷红'，春草曰'寒绿'。"**

**徐兴公《笔精》卷六**一口气举了**五十九例**：

| 代词 | 所指 |
|---|---|
| 金鳞 | 甲 |
| 泉合 | 水 |
| 宝粟 | 珠钏 |
| 仙妾 | 嫦娥 |
| 玉弓 | 月 |
| 鸡筝 | 鹍弦 |
| 龙材 | 笋 |
| 淡蛾 | 萤 |
| 海素 | 鲛绡 |

（徐书没举"圆苍"，见李贺《吕将军歌》。）

### 也有"避熟求生"失败的例子

《洛姝真珠》首句"**真珠小娘下青廓**"——"青"即"碧"，"廓"即"落"或"空"。"碧落""碧空"本已是天的惯用代词，李贺**再逐字替换**，就"较'圆苍'更僻诡无味"，与唐代那种造作的"虬户""筱骖"没有区别。

> **钱锺书的判断**：整句不过是说"真珠如天仙降尘世"。不说破物名、只言其性状，这种做法**源头是韩愈（退之）、司空图（表圣）的"以文为戏"**——如韩愈呼笔为"毛颖"、呼镜为"金炯"。

### 另有几处"约缩"字

- "**书客**"（《秋来》《高轩过》）——"书生作客"缩为"书客"；"书生之鬼"缩为"**书鬼**"。虽不费解，却**易误解**（会以为像"剑客""墨客"的"客"、"酒鬼""色鬼"的"鬼"）。
- 比起杜甫《八哀诗》把"异姓王"缩为"异王"，"书客""书鬼"还算不上太不通。

## 二、一个有趣的"折柳"专题

《致酒行》"**主父西游困不归，家人折断门前柳**"，王注说"攀树而望行人之归，至于断折"，钱锺书说"**尚未中肯**"，于是展开一个大讨论。

### 古有折柳送行之俗

杨慎（升庵）《折杨柳》咏此，被推为绝唱：

> "垂杨垂柳绾芳年，飞絮飞花媚远天。别离河上还江上，抛掷桥边与路边。"

### 但还有第二种：折柳"寄远"

> **"送一人别，只折一次便了；寄远则行役有年，归来无日，必且为一人而累折不已。"**

（送别只折一次；寄远则行人多年不归，要为同一个人**反复折个不停**。）

**"赠别之折柳"**（折一次）：

- 白居易《青门柳》："**长条折尽减春风**"
- 邵谒《苦别离》："**若遣折杨柳，此地无树根**"
- 鱼玄机："**折尽春风杨柳烟**"

**"寄远之折柳"**（反复折）：

- 卢照邻："**攀折聊将寄，军中书信稀**"
- 张九龄："**纤纤折杨柳，持此寄情人**"
- 李白："**攀条折春色，远寄龙庭前**"；又有"**无令长相思，折断杨柳枝**"
- 孟郊："**赠远累攀折，柔条安得垂**"

### 回到李贺

> **"长吉诗正言折荣远遗，非言'攀树远望'。"**

"主父不归"，家人**折柳频频寄去**，以致枝秃树残。**这是"寄远催归"之意**——"园中柳折频频寄，堪比唱'陌上花开缓缓归'"。

> **一个漂亮的对照**：越使、驿使"**寄梅**"是诗文中常见的典故；钱锺书借李贺这句，拈出"**寄柳**"的古俗，与之配对。

## 三、本节的核心批评：李贺的短处

### 通篇不见本名的"谜语诗"

- 《咏竹》五律："黏著呆滞"。
- 《剑子歌》《猛虎行》虽"警炼佳篇"，却像"**博士书券，通篇不见'驴'字**"。
- 王夫之（船山）讥杨亿《汉武》诗是"**汉武谜**"；钱锺书说李贺这两首**也是"剑谜""虎谜"**。

### 一针见血的诊断

> **"盖性僻耽佳，酷好奇丽，以为寻常事物，皆庸陋不堪入诗。力避不得，遂从而饰以粉垩，绣其鞶帨焉。微情因掩，真质大伤。"**

（他性情偏执、酷好奇丽，觉得寻常事物都庸陋不堪入诗；**避不开时，就给它涂脂抹粉、绣上花边**。结果——**细微的情感被掩盖，真实的质量被损伤**。）

> **两句对举，极其精警**：
> **"牛鬼蛇神，所以破常也；代词尖新，所以文浅也。"**
> （用牛鬼蛇神是为了**打破常规**；用尖新代词是为了**掩盖浅薄**。）

### 引用前人的批评

> **张戒《岁寒堂诗话》**："长吉诗'**只知有花草蜂蝶，而不知世间一切皆诗**'，实道著长吉短处。"

（这句话正是说中了李贺的短处——他只知道花草蜂蝶可以入诗，不知道**世间一切都是诗**。）

### 最终定评

> **"长吉铺陈追琢，景象虽幽，怀抱不深；纷华散藻，易供挦撦。若陶、杜、韩、苏大家，化腐为奇，尽俗能雅，奚奴古锦囊中，固无此等语。"**

（李贺铺陈雕琢，景象虽幽深，**怀抱却不深**；辞藻纷华，容易被人摘取。而陶渊明、杜甫、韩愈、苏轼这些大家，**能化腐朽为神奇、化俚俗为高雅**，李贺那个"古锦囊"里，本没有这样的话。）

> **一句话的结论**："**蹊径之偏者必狭，斯所以为奇才，亦所以非大才欤。**"
> （路子偏的人必然狭窄——这正是他成为"奇才"的原因，也是他不是"大才"的原因。）

## 四、名词小词典

| 名词 | 说明 |
|---|---|
| 代词 | 不直说物名，用代称，如剑曰"玉龙" |
| 圆苍 | 李贺对"天"的代词，见《吕将军歌》 |
| 冷红 / 寒绿 | 李贺对"秋花""春草"的代词 |
| 毛颖 / 金炯 | 韩愈呼笔、呼镜的戏称，代词的源头 |
| 书客 / 书鬼 | "书生作客""书生之鬼"的缩略 |
| 折柳 | 古俗：赠别折一次，寄远反复折 |
| 寄梅 | 越使、驿使寄梅的典故，与"寄柳"配对 |
| 汉武谜 | 王夫之讥杨亿《汉武》诗语，喻不见本名 |
| 挦撦 | 摘取、割裂（词藻） |

## 六、给初学者的思考题

1. 李贺用代词，是"创新"还是"炫技"？钱锺书的态度是什么？
2. "牛鬼蛇神，所以破常也；代词尖新，所以文浅也"——为什么"破常"是褒、"文浅"是贬？
3. "折柳"为什么会有"赠别"和"寄远"两种？这个区分帮我们更准确理解了《致酒行》哪一点？
4. 为什么说陶、杜、韩、苏"化腐为奇，尽俗能雅"，而李贺做不到？
5. 你同意"奇才而非大才"这个评价吗？"奇才"和"大才"的区别是什么？
